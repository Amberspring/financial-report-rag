# 可直接用于简历的正文

**金融研报智能问答 RAG｜PyMuPDF、FAISS、BM25、BGE、CrossEncoder、FastAPI**

面向财报多栏文本、长表格和数值推理场景，构建 PDF 解析、表格整体保护切块、向量/关键词混合召回、CrossEncoder 重排、页码引用、低置信拒答和可追溯评测链路。在 FinQA 官方 test 的确定性 100 问子集上，以 131 个唯一页面构建 3,321 chunks；同一 512 字符/Flat 设置下实测 BGE dense、BM25、BGE hybrid 和 RRF+MiniLM 重排，Recall@5 分别为 75.83%、63.83%、72.17% 和 75.33%。重排将混合召回 Recall@5 提升 3.16 个百分点，但 CPU 平均查询延迟由 113.2ms 增至 3086.2ms，且未超过 dense 单路，基于结果保留 dense 作为低延迟配置。实现受控数值计算、单位核验与证据回传，并对 FinQA 标签/程序不一致案例保留审计记录。

边界：Recall 是证据召回率，不是答案正确率；真实 168 页 PDF 解析耗时很长且表格识别仍需人工 QA；自然语言数值规划覆盖率有限。
