# badcase 与使用边界

- TF-IDF 的相似表述无法稳定定位多公司/跨年份数值；逐问检索失败在 *-traces.json 中保留。
- RRF 有时稀释 BGE dense 的正确候选；重排提高混合 Recall@5，但没有超过 dense 的 Recall@5，且延迟明显增加。
- 大表保持完整避免跨行丢失，但 encoder 截断可能忽略后半表；不能把表格保护说成完整表格推理。
- 无年份/多步骤/文本数字/复合增长等问题常被规则规划器拒答；修复后自然语言覆盖只有 6%。显式计算器是确定性工具，选错单元格仍会产生错误业务含义。
- 基点变化曾被误作百分比增长，已增加拒答和回归检查。原报告保留错误，不覆盖美化。
- FinQA 的显示答案与程序值有时不一致，且百分比可显示为百分数或比例。raw exe_ans 和显示单位检查分开报告。
- 拒答阈值是词汇启发式，不是经过校准的置信概率；没有发布不存在的拒答精确率或投资预测能力。
- PDF 无 OCR，检测到扫描/空文字会报错。完整 168 页解析耗时超过 2 小时，适合离线入库，不能放进实时问答请求。
