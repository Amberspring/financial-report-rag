# 实验报告 — 2026-10-05

## 数据与协议

FinQA 官方 test 中确定性选择 100 个问题，另保留 40 dev；语料覆盖 131 个唯一页面。512 字符正文切块与整体表格形成 3,321 chunks。gold 只用于评测；全库检索不输入 gold 文档 ID，也不输入程序、答案或证据标签。

Recall@k：对每问计算 top-k 召回覆盖的 gold 来源片段 ID 比例，再宏平均。完整表格 chunk 覆盖其行 ID；这项指标是证据召回，不是答案正确率。原子表格可能超过 512 token，神经 encoder 会截断；检索回来的原文仍保留完整表格。

27 组 TF-IDF 消融：256/512/1024 字符 × Flat/HNSW/IVF × dense/BM25/RRF。另 4 组真实 BGE / CrossEncoder 实验。

## 同一 512 字符 / Flat 设定下的真实模型比较

| 方案 | Recall@3 | Recall@5 | Recall@10 | 平均查询 ms | P95 ms |
|---|---:|---:|---:|---:|---:|
| BGE dense | 70.33% | 75.83% | 80.33% | 110.6 | 144.4 |
| BM25 | 55.67% | 63.83% | 71.50% | 38.3 | 61.3 |
| BGE hybrid | 64.67% | 72.17% | 77.50% | 113.2 | 150.0 |
| BGE + RRF + MiniLM 重排 | 71.67% | 75.33% | 81.00% | 3086.2 | 4775.0 |

重排使混合召回 Recall@5 从 72.17% 到 75.33%，但 CPU 平均查询延迟从 113.2ms 到 3086.2ms。BGE 单路 dense 的 Recall@5 为 75.83%，因此不能宣称混合重排全面优于 dense。没有把逐项最高结果拼成一个不存在的系统。表中延迟是在共享本机上测得，未经独占机器容量校准。

## 数值推理与标签审计

确定性单元格计算器通过单元测试与真实 HTTP 例子验证；支持受控六种运算，包含证据、单位及年份核验。自然语言规划器只覆盖明确两年份与唯一指标行，不能称为完整 FinQA 解题模型。

初次 100 问评测：7 问有输出，直接对 raw exe_ans 匹配 2 问。发现比例/百分比的表示差异及 basis points 被误认成增长率的问题。保留原结果 numerical-cases.json 和 finqa-benchmark.json，没有覆盖失败记录。

增加不支持的基点/复合年化约定拒答后，同一公开子集复评仅回答 6/100。raw exe_ans 匹配 2/6；与题目显示答案按同单位比较为 6/6。后者只是单位/标签审计，**不是标准 FinQA 执行准确率，不是 100% 端到端正确率**，且属于见过测试案例后的 bug 修复复评，不能说成新独立测试。完整明细在 numerical-audit.json。

例如 SNA/2007/page_49.pdf-4 的显示答案为 2.7%，程序使用 add 后除以旧值，exe_ans=2.02778；本系统按表格计算增长为 2.7778%。这类 label/program 不一致单独披露，不擅自修改官方标签。自然语言覆盖低是当前明确限制，实际功能应优先采用显式单元格计划。

## 真实 PDF 解析审计

从 Microsoft 投资者资料下载 2024 10-K，168 页实际解析为 474 blocks、301 个启发式 table blocks、1436 chunks；耗时 10580.7 秒。完整 PDF 与索引不分发。抽取耗时长、页级列顺序和表格检测需要人工 QA；这些数量不证明识别准确率。原文 SHA256 与 URL 在 real-pdf-audit.json。PDF 审计语料和 FinQA 检索语料互相独立。

单位检查针对显式百分比/货币符号，不能自动判断每股、百万、币种司法辖区等全部财务维度；无符号数值使用 reported_units 并保留表格标签。不得据此声称通用财务口径校验。
